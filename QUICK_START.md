# 🚀 GUIDE DE DÉMARRAGE RAPIDE

## Lancer l'application en 3 étapes

### Sur Linux/Mac :
```bash
./start.sh
```

### Sur Windows :
Double-cliquez sur `start.bat` ou exécutez dans le terminal :
```cmd
start.bat
```

### Avec Docker Compose directement :
```bash
docker-compose up --build
```

## Accéder à l'application

Une fois lancée, ouvrez votre navigateur :
```
http://localhost:5000
```

## Arrêter l'application

Appuyez sur `Ctrl+C` dans le terminal, puis :
```bash
docker-compose down
```

## Premiers pas

1. **Inscrivez-vous** : Créez un compte utilisateur
2. **Connectez-vous** : Utilisez vos identifiants
3. **Jouez** : Résolvez les énigmes de programmation
4. **Attention** : Les mauvaises réponses déclenchent des screamers ! 👻

## Énigmes disponibles

- 🐍 **Python** : Corrigez du code buggé
- 🔍 **F12** : Trouvez le flag caché dans la console
- 🗃️ **SQL** : Exploitez une vulnérabilité SQL injection
- ⚙️ **C** : Trouvez les erreurs de syntaxe

## Astuces

- Utilisez F12 pour ouvrir les outils de développement
- Lisez attentivement les indices
- N'ayez pas peur des screamers (mais préparez-vous !)
- Chaque énigme résolue vous rapporte 100 points
