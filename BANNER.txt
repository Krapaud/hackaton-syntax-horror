📋 MENU RAPIDE :

  1️⃣  DÉMARRAGE RAPIDE
      └─ ./start.sh (Linux/Mac) ou start.bat (Windows)
      └─ Ou : docker-compose up --build
      └─ Accès : http://localhost:5000

  2️⃣  ÉNIGMES DISPONIBLES
      ├─ 🐍 Python : Corrigez du code buggé
      ├─ 🔍 F12    : Trouvez le flag caché
      ├─ 🗃️  SQL    : Exploitez une injection SQL
      └─ ⚙️  C      : Trouvez les erreurs de syntaxe

  3️⃣  FONCTIONNALITÉS
      ├─ ✅ Authentification complète
      ├─ ✅ Système de score et progression
      ├─ ✅ Leaderboard des meilleurs joueurs
      ├─ ✅ Screamer sur mauvaise réponse
      └─ ✅ Interface Halloween effrayante

  4️⃣  TECHNOLOGIES
      ├─ Backend  : Python + Flask + SQLAlchemy
      ├─ Frontend : HTML5 + CSS3 + JavaScript
      ├─ Database : SQLite
      └─ DevOps   : Docker + Docker Compose

🚨 DÉPANNAGE RAPIDE :

    ❌ Port 5000 occupé
       → Modifiez dans docker-compose.yml : "8080:5000"

    ❌ Erreur de base de données
       → rm -rf data/ && docker-compose up --build

    ❌ Permission denied (Linux)
       → sudo chown -R $USER:$USER .

    ❌ Docker non installé
       → https://docs.docker.com/get-docker/
